# インベントリシステム (Inventory System)

`graal-ansible` がサポートするターゲットノード管理（インベントリ）の仕様を定義します。

## 1. サポート形式

### 1.1 静的ファイル
- **INI 形式**: セクション、変数、子グループ定義をサポート。
- **YAML 形式**: 階層構造、変数定義をサポート。

### 1.2 動的更新 (Runtime Update)
- **add_host モジュール**: 実行時に新しいホストをインベントリに追加し、グループに割り当てる機能をサポート済み。
- **group_by モジュール**: ファクトに基づいて実行時にグループを動的に作成する機能をサポート済み。

### 1.3 外部インベントリ (Dynamic Inventory)
- **インベントリ・プラグイン/スクリプト**: JSON 形式等を出力する外部プログラムとの連携は、現在**設計策定中**です。詳細は [インベントリシステムの実装詳細](../implementation/Inventory-System.md#5-外部インベントリの統合設計-external-inventory-integration-design) を参照してください。

## 2. 実装上の留意点 (Implementation Considerations)

### 2.1 グループ変数の階層構造
- **仕様**: 親グループよりも子グループの変数を優先する標準的な挙動を実装。
- **状況**: 実装済み。詳細は [インベントリシステムの実装詳細](../implementation/Inventory-System.md) を参照。

### 2.2 ホスト（ターゲットノード）パターンのマッチング
- **サポート範囲**: 単純なホスト名、グループ名、`all` に加え、カンマ(`,`)またはコロン(`:`)区切りの複数パターン指定、およびワイルドカード(`*`)によるマッチングをサポート。
- **制限**: レンジ指定（`web[0-5]`）などは将来的な課題。

### 2.3 インベントリの自動検出
- **方針**: 環境依存を避けるため、`-i` オプションによる明示的な指定を推奨。
- **デフォルト探索**: カレントディレクトリの `hosts` ファイル等の最小限の探索に留める。
